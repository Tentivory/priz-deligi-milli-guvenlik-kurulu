# Priz Deliği Milli Güvenlik Kurulu

Yanlış fişi yanlış deliğe sokmak, bu kurumun resmi görüşüne göre **sıradan bir ev kazası değildir**.  
Bu bir sınır ihlalidir. Bu bir protokol sapmasıdır. Bu, prizin rızası alınmadan yapılan bir giriş girişimidir.

Bu depo, söz konusu ihlali bilimsel ciddiyetle (ama bilimsel olmadan) belgeler. Kod **gerçekten çalışır**. Prizler artık sınırdır.

## Ne yapar?

`priz_mgk.py` rastgele (veya sizin verdiğiniz) bir fiş ile bir deliği eşleştirir, tehdidi adlandırır, aciliyet puanı verir ve kurul kararı basar.

```bash
python3 priz_mgk.py
python3 priz_mgk.py "saç kurutma makinesi" "Avrupa tipi yuvarlak"
```

Örnek çıktı, bir tutanak gibi durur çünkü tutanaktır.
